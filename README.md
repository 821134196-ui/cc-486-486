# 散装砂浆提货与过磅核对系统（虚构演示）

建材门店散装砂浆提货全流程模拟：预约排队 → 车辆入场首次过磅（皮重并锁定订单）
→ 选料仓并发料 → 装料后二次过磅（含水修正得出场净重）→ 客户确认/补装 →
核验放行并生成不可变结算快照 → 差额退款双角色复核。

车辆车牌、载重、金额、付款回执、地磅读数均为**虚构数据**。仅依赖 Python 3.10+
标准库（sqlite3 / http.server），无需安装任何第三方包。

## 启动

```bash
python3 -m mortar          # 重建样例数据并启动 Web，默认 http://127.0.0.1:8000
python3 -m mortar seed     # 只重建样例数据（超量/断磅/拒签/争议/并发抢料/过号）
python3 -m mortar test     # 运行 19 条领域规则测试
```

环境变量：`MORTAR_PORT`（默认 8000）、`MORTAR_DATA`（默认 `./data`）、
`MORTAR_GRACE`（呼号过号宽限秒数，默认 45）。

数据落位：

- `data/mortar.db` —— 订单、车辆、料仓、过磅/装料事件、异常、改重、退款（SQLite + WAL）
- `data/images/` —— 车辆入场照与出场磅单（占位 PNG，元数据入库）

## 界面角色（右上角切换，本地演示无真实鉴权）

| 角色 | 职责 |
|---|---|
| 调度员 | 登记订单、确认付款、呼号、入场过皮重、放行出场 |
| 磅房操作员 | 选料仓发料、二次过磅、补装、发起人工改重 |
| 客户 | 确认重量签收 / 拒签 / 提出含水争议 |
| 当班主管 | 关闭异常、复核人工改重（不能是发起人本人） |
| 财务专员 / 财务主管 | 退款发起 / 退款复核付款，须不同人 |

## 预置样例（一条启动命令即备齐）

| 订单 | 场景 |
|---|---|
| 已出场 #首单 | 两轮装料 + 订单余量内补装 + 结算快照，差额退款待财务主管复核 |
| 排队中 | 等待呼号 |
| 提货中 | 已过皮重待选仓；**装料超量**（超车型额定载质量，闸门冻结） |
| 提货中 | **地磅中断**：二次过磅失败留痕，恢复通讯后可重新过磅（控制台切换中断开关） |
| 提货中 | **客户拒签**：主管关闭异常后客户方可再签收 |
| 提货中 | **含水争议**：3%→5% 改重申请在复核台待主管批准，批准后自动重算净重 |
| 排队中 | **车型不符**：三轴车到场/预约两轴，留痕并劝返 |
| 排队中 | **过号**：呼号超宽限未入场，后台线程自动释放并计数，可重新呼号 |
| 两笔并发 | A2 仓仅剩 8t，各申请 5t → 按锁定量分配 **5.0t + 3.0t** |

## 核心规则

- **车辆唯一**：部分唯一索引 `vehicle_service(plate) WHERE status='active'`，
  一辆车同一时刻只能服务一笔订单；放行后才能服务下一单。
- **库存锁定**：授予即原子扣减（`UPDATE ... WHERE stock>=?`），最后一段库存被
  并发装料时后到者按扣减后的余量重新分配；授予量同时受订单余量约束。
- **净重计算**：首轮 `净重 = 毛重 − 皮重`；补装轮 `净重 = 本轮毛重 − 上轮毛重`
  （车辆不离场），再乘 `(1 − 含水率%)` 得出场净重。
- **补装**：仅允许签收后、订单有余量、车辆未放行时开新一轮；累计签收超订单即
  留 `over_order_after_topup` 痕迹并禁止签收。
- **放行不可逆**：所有轮次签收且无未关闭异常才放行；生成结算快照（JSON 含每轮
  皮重/毛重/含水/净重与价格版本），轮次置 `gate_released`，之后禁止重开装料、
  补装、改重。
- **退款幂等**：一单一个幂等键 `REFUND-<order_id>`，重复发起返回原单；
  财务发起、财务主管（且非发起人）批准后付款并回写快照。
- **留痕类型**：车型不符、料仓错选、皮重异常（偏离备案 ±12%）、装料超量、
  地磅中断、含水争议、补装后超单、客户拒签；人工修订在界面以
  <s>原值</s> → **新值** 紧邻显示，全部进入追加写的重量事件流。

## 代码结构

```
mortar/
  config.py      路径/角色常量/皮重容差
  db.py          SQLite schema（事件流、部分唯一索引、CHECK 约束）
  adapters.py    模拟地磅（可中断）/料仓/付款回执/图片采集
  services.py    领域服务：队列、过磅、锁定、补装、签收、结算、复核、过号扫描
  seed.py        虚构基础数据与异常样例编排
  web.py         http.server 界面：排队屏/过磅页/料仓刻度/复核台/控制台
  tests/         19 条测试：车辆唯一、库存锁定(含多线程)、净重、放行不可逆、退款幂等
```
