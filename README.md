# 散装砂浆提货与过磅核对系统（虚构演示）

建材门店散装砂浆从**付款入队 → 车辆入场 → 两次过磅 → 装料/补装 → 出场核验 → 结算退款**的全流程核对系统。
仅依赖 Python 3.10+ 标准库（`http.server` + `sqlite3`），**车辆牌号、重量读数与金额均为虚构数据**。

## 一条命令启动

```bash
python3 run.py            # 首次启动自动建库并播种；之后保留数据
python3 run.py --reset    # 重置库与图片，重新准备“超量/断磅/拒签”等异常样例后启动
python3 run.py --seed-only# 只准备样例数据，不起服务
```

打开 <http://127.0.0.1:8000> ，默认端口 8000，可用 `--port` 修改。

## 界面与角色

顶栏可切换五个虚构角色（改重与退款要求**不同角色的第二人**复核）：
张调度(dispatcher) / 李司磅(weigher) / 王装载(loader) / 赵收银(cashier) / 孙主管(supervisor)。

- **排队大屏 `/`**：突出**车号后四位**（大号工程黄）、**砂浆型号**、**当前环节**；下方料仓直立刻度。页面 15 秒自动刷新。
- **订单登记 `/orders`**：客户代号、型号、料仓、预约时段、车型、价格版本；模拟付款回执确认后进入提货队列。
- **两次过磅 `/weigh` 与订单作业台**：**皮重 / 毛重 / 净重竖直对齐**，净重显著放大；含水按百分比折干。
- **料仓库存 `/silos`**：直立刻度管显示库存与在锁量（深蓝斜纹覆盖层），附库存变动流水。
- **异常留痕 `/exceptions`**：八类异常 + 过号，全部留痕可追溯。
- **结算复核 `/reviews`**：人工改重、退款的申请/复核台；演示角色冲突与退款幂等。

配色：水泥灰底、工程黄强调、深蓝导航与卡片。

## 业务规则

状态机：
`PAID 已付款 → QUEUED 入场 → TARE 皮重+锁库存 → LOADING 装料 → LOADED → WEIGHED 复磅
→ CONFIRMED 客户确认(结算快照) → RELEASED 放行（终态）`；
异常终态：`REJECTED 拒签 / NO_SHOW 过号 / CANCELLED 取消退款`。

- **车辆唯一**：一个车牌同一时刻只能绑定一笔在场订单；放行后释放。车型不符留痕并阻断，主管可裁定。
- **库存锁定**：首磅时按订单余量锁定；最后一段库存被并发装料时**按实际可锁量分配**，装料不得超过本单锁定量（8 线程并发测试不超卖）。
- **两次过磅**：净重 =（毛重 − 皮重）×（1 − 含水%）；地磅中断留痕，恢复后可重试；皮重超出车型合理区间需主管确认。
- **补装**：仅允许在订单余量（折干）内；补装后超单单独留痕 `REFILL_EXCEED`。
- **出场不可逆**：客户确认重量后生成**结算快照**（价格版本固定），放行后不能重开装料或倒流。
- **双人复核**：人工改重与退款都需另一角色复核；修订在审计时间线中**紧邻原值**（删除线）保留。
- **退款幂等**：按订单生成幂等键 `REFUND:<订单号>`，重复申请返回原复核单、重复审批不二次打款。
- **过号释放**：进程内守护线程每 30 秒扫描，预约时段过后 15 分钟未入场的 PAID 单置 `NO_SHOW`。

## 预置样例（`--reset` 后）

13 笔订单覆盖队列中各环节，并已产生留痕：**装料超量、料仓错选、补装后超单、地磅中断、客户拒签、含水争议**；
另有一笔预约时段已过的订单供过号任务自动释放。过磅页可一键“模拟地磅中断/恢复”。

## 数据存放

- SQLite：`data/app.db`（订单、重量事件、异常、复核单、库存流水）
- 本地图片：`data/images/vehicles/*.svg`（虚构车辆图）、`data/images/slips/*.svg`（虚构磅单）

## 测试

```bash
python3 -m unittest discover -s tests -v
```

`tests/test_domain.py`（14 个用例，每个使用独立临时库）覆盖：

1. **车辆唯一**：同车牌冲突拦截 + 放行后释放；车型不符留痕
2. **库存锁定**：末段库存按锁定量分配、装料不超锁定、8 线程并发不超卖
3. **净重计算**：含水折算、主管裁定后重算并保留原值、断磅留痕可重试
4. **放行不可逆**：放行后装料/复磅/确认/再放行全部被状态机拒绝
5. **退款幂等**：重复申请同单、重复审批不二次打款、不同角色复核、全额退讫取消并释放锁定
6. 人工改重双人复核与审计原值保留

`tests/smoke_http.py` 是针对运行中服务的 20 步端到端脚本（需先 `python3 run.py`）：

```bash
python3 run.py --reset --seed-only && python3 run.py --port 8000 &
python3 tests/smoke_http.py
```
